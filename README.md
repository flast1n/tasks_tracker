# Smart Task Tracker

Простий та легкий інструмент для керування повсякденними завданнями. Допомагає відстежувати статуси задач і тримати справи під контролем без зайвих налаштувань.

## 🚀 Можливості

* **Додавання та видалення:** Швидке створення й вилучення задач.
* **Відстеження статусів:** Позначення завдань як *To Do* або *Done*.
* **Фільтрація:** Зручний перегляд активних та завершених задач.
